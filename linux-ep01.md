# Terminal & Command Line Basics - Episode 1: Essential File Navigation

Welcome to **Episode 1** of the *Terminal & Command Line Basics* series! 

In this session, you'll learn the 5 most essential file navigation commands that every developer, system administrator, and tech enthusiast needs to master to navigate their system's directories directly from the terminal.

---

## 📌 Commands Covered

| Command | Description | Example Usage |
| :--- | :--- | :--- |
| `pwd` | **Print Working Directory** – Find out your current directory path. | `pwd` |
| `ls -la` | **List Directory Contents** – View all files and directories, including hidden ones (`.files`), in a detailed list format. | `ls -la` |
| `cd` | **Change Directory** – Navigate between folders in your system. | `cd path/to/folder` |
| `mkdir -p` | **Make Directory** – Create nested directory structures instantly without failing if parent folders don't exist. | `mkdir -p project/src/components` |
| `clear` | **Clear Screen** – Clean up your terminal interface for a fresh view. | `clear` |

---

## 🚀 Getting Started

1. Open your terminal application (e.g., Terminal on macOS/Linux, Git Bash, or WSL on Windows).
2. Follow along with the video steps to test each command in your own environment.
